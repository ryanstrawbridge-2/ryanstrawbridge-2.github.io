# Project diagrams

One deck per project. Every shape, arrow and label is native, so the decks
stay editable in Google Slides, Canva or PowerPoint. Slide 1 of each deck is a
read-me: where each fact came from, and what to check. Don't export it.

## Edit in Google Slides

1. Drive → New → File upload → pick a `.pptx` from this folder.
2. Right-click it → Open with → Google Slides. (Or File → Import slides into a
   deck you already have.)

Canva: Create a design → Import file → pick the `.pptx`.

## Put a diagram on the site

1. In Slides: File → Download → PNG image (current slide). The slides are
   16:10, so that comes out at the 1600 × 1000 the site's figures expect.
2. Rename it `PREFIX_title.png`, e.g. `Lift_three-points.png`, and drop it in
   `photo-inbox/`.
3. In studio, open Media and pick it. Or set it as the `image` on the matching
   placeholder figure in Pages CMS. The `plan` text tells you which one.

## Rebuild from source

The decks are generated by `src/*.js`. Edits made in Google Slides don't flow
back here, so once you start hand-editing a deck, Slides is the master copy.

```bash
cd diagrams && npm install && npm run build      # all decks
node src/build-all.js lifting-frame              # one deck
./render.sh lifting-frame                         # PNG previews via Keynote
```
